☁️ Cloud-Based E-Commerce Application Deployment Using AWS DevOps

📌 Project Overview
Designed and deployed a cloud-based e-commerce web application on Amazon Web Services (AWS) by implementing an automated CI/CD workflow. The project integrates GitHub with AWS CodePipeline and AWS CodeDeploy to streamline application delivery and deploy code updates to an Amazon EC2 instance with minimal manual intervention.
This project was completed as part of an AWS DevOps Internship, providing hands-on experience in cloud infrastructure, deployment automation, version control, and CI/CD pipeline management.

🎯 Project Goals
- Host an e-commerce web application on AWS cloud infrastructure.
- Build an automated CI/CD pipeline for continuous application delivery.
- Connect GitHub source code with AWS deployment services.
- Configure automated application updates on an EC2 instance.
- Apply DevOps principles to improve deployment consistency and efficiency.

🧰 Technology Stack

Cloud Platform: Amazon Web Services (AWS)

AWS Services: AWS CodePipeline, AWS CodeDeploy, Amazon EC2

Version Control: Git, GitHub

Application: E-Commerce Web Application

🔄 Implementation Workflow
1.Source Code Management: Application code is maintained in a GitHub repository.
2. Pipeline Trigger: AWS CodePipeline detects configured source-code changes.
3. Deployment Automation: AWS CodeDeploy manages the deployment of the updated application to the target EC2 instance.
4. Application Update: The latest deployed version becomes available through the hosted web application, subject to successful deployment and application health.
5. Continuous Delivery: The workflow reduces repetitive manual deployment tasks and simplifies application updates.

🏗️ System Architecture

Developer → GitHub Repository → AWS CodePipeline → AWS CodeDeploy → Amazon EC2 → E-Commerce Web Application

✨ Key Features

- GitHub integration for source code management.
